# 0030 - 2D-Karten optisch aufwerten

## Beschreibung

2D Karten optisch aufwerten

## Details

Betroffenes System vermutlich: `Assets/Scripts/Grid/PipeVisual.cs` - zeichnet
die 2D-Pipe-Darstellung (Karten) zur Laufzeit rein prozedural per
SpriteRenderer (Hintergrund, Hub, Arme, Rollen-Label siehe Ticket 0016).

Beschreibung ist bewusst vage ("optisch aufwerten") - konkrete
Gestaltungswünsche (Farben, Formen, Texturen, Schatten/Kanten o.ä.) müssen
noch geklärt werden, bevor das Ticket umgesetzt werden kann.
